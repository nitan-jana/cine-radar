# Cine Radar

A movie search app built on the [TMDB](https://www.themoviedb.org/) API: trending and popular films, search, movie pages with cast and trailers, and actor pages.

Built with React, TypeScript, TanStack Query, React Router, Tailwind CSS, and Vite.

## Run locally

1. Copy `.env.example` to `.env` and set `VITE_TMDB_ACCESS_TOKEN` to your TMDB API read access token.
2. `pnpm install`
3. `pnpm dev`
